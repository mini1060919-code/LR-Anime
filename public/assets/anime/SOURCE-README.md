# LR-Anime M3：四名角色圖像整合包

包含 4 張全身立繪、4 張 3×2 表情表、20 張 512×512 表情分圖、4 張 512×512 頭像，以及素材 manifest。

## 注意
- 角色立繪與表情表為生成美術，已分割出單獨的頭像與表情檔；尚未安裝到 GitHub。
- 請於遊戲中檢查人物一致性、像素邊緣、透明度與裁切。尤其 **悠真** 原始表情表背景透明度殘留，這裡已做初步 alpha 修正，需視覺驗收。
- 表情表以 3 欄×2 列切割，每格 512×512；第六格留白未納入。
- 全身立繪為 1024×1536；表情與頭像為 512×512。角色頭像目前使用 neutral 表情的完整方形裁切，並非額外繪製的獨立頭像。
- 以上是 M3 美術交付，不代表 M3 程式或 v6 存檔整合完成。
- 原創生成素材來源：OpenAI 圖像生成；正式發布時仍需遵守適用服務條款，不對排他著作權或商標權作保證。

## 整合
將 `public/assets/anime/` 原樣複製到遊戲專案，先由 Codex 檢查 M2 角色面板載入 API，再將 manifest 的 ID 與遊戲居民建立穩定映射。缺少檔案需回退預設肖像，不可變更既有居民 ID，並須通過存檔及 UI 回歸測試。
