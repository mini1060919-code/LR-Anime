# E-04｜角色效率與貢獻 v0.1

| 展示 | 真實來源與限制 |
|---|---|
| 工作狀態 | survivor.buildingId 與建築 workers，沿用 `src/needs/simulation.js:onDuty` 的啟用、供電、HP 和職位判定；派工和實際工作分列。 |
| 團隊技能加成 | `src/progression/work.js:abilityMultiplier` 為參與者平均技能，最多加 10%。已停用效果時顯示停用；未參與時不指派個人加成。 |
| 需求效率 | `crewEfficiency` 回傳合格團隊成員 needsEfficiency 的平均，只有效果開啟且資料有效才顯示。 |
| 個人進度 | 既有 abilityRanks、experience，取驗證的居民資料。 |
| 實際產出 | 經濟／採集／研究使用不同路徑；只有該用途確有相應實測單位才顯示實際值。現行 work receipt 是短暫結算證據，不能當作個人歷史產量。 |

分開顯示基礎值、有效修正及未知數據。顯示時以單位及 locale 格式化，保持計算精度，禁止從團隊產出反推個人份額。驗收開關啟閉、空工位、停電、不同技能與需求效果，對照同一模擬步的原有函式輸出及來源。
