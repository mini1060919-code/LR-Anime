# D-05｜人物名冊與招募 UI v0.1

在既有角色面板加入「招募／Recruitment」入口，保留既有倖存者檔案與 Three.js 地圖操作。名冊依穩定模板 ID 顯示名稱與剪影，點選可看背景、職業、特質、技能方向、逐條解鎖條件、床位與價格。已加入明細沿用真實 resident uid。參謀資訊與可派工名冊分開，legacy 居民照原紀錄呈現。

| 狀態鍵 | 繁中／English | 操作 |
|---|---|---|
| locked | 未解鎖／Locked | 檢視已滿足及待滿足條件，逐條列出可核證數值。 |
| available | 可招募／Available | 查看費用、床位與影響，玩家自行確認邀請。 |
| pending | 等待黎明確認／Pending dawn confirmation | 可取消尚未提交的意圖，並顯示當前限制可能變動。 |
| joined | 已加入／Recruited | 開啟既有居民詳情；若已離隊，顯示歷史收據。 |
| failed | 招募未完成／Recruitment incomplete | 分別提示床位不足、存量不足、狀態變動、儲存失敗或請求無效。提供可回復途徑，資料變動前要求玩家重新確認。 |

核心雙語回饋「沒有空床位／No bed available」、「基礎存量不足／Reserve stock too low」、「無法儲存，請重新載入後確認／Could not save. Reload before confirming again」。候選門檻及即時容量並列，不提前宣告加入。1000px 用側面板，390px 單欄捲動，保留關閉及返回。鍵盤可遍歷、Esc 退出、焦點還原，面板操作不穿透到地圖。介面換語言保持選取與確認狀態，不重送。待做兩語、窄寬尺寸、鍵盤／觸控與原操作回歸。
