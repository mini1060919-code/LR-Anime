# C-03｜風險判定與優先級 v0.1

企劃門檻供設計審查。以 [C-01](C-01.md) 與 [C-02](C-02.md) 的同份快照判定。缺值列資料不足，該規則不出警示。沒有規則命中只顯示「目前無可確認警示」。

| 規則 ID | 觸發（有限且已知資料） | 優先級與證據 |
|---|---|---|
| water.empty | 活人口 > 0 且水量 < 1 | P1，庫存及活人口。遊戲每次飲水需一單位。 |
| food.empty | 活人口 > 0 且食物 < 1 | P1，庫存及活人口。遊戲每次進食需一單位。 |
| health.critical | 任一健康 < 30 | P1，居民 ID、健康值、命中數。沿用現行 Critical。 |
| defense.unstaffed | 已知至少一座存活塔，且無可用塔 | P2，塔 ID、可用數與受阻原因。無塔另列配置現況，未推定基地戰力。 |
| fatigue.exhausted | 任一疲勞 ≥ 75 | P2，居民 ID、疲勞、命中數。沿用 Exhausted。 |
| morale.low | 任一士氣 < 30 | P3，居民 ID、士氣、命中數。沿用 Low spirits。 |

同級依表列順序，居民與建築 ID 升冪。每份日報每規則一條，群組顯示命中數與展開明細。P1 顯示在報告頂部，P2/P3 隨後。相同日報重讀及換語言共用同一結果。建議只反映快照時點，不能推估剩餘天數、下一次襲擊或倖存機率。驗收需覆蓋等於 1／30／75、零人口、未知欄位、多規則同時命中及排序，待執行。
