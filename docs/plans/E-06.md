## 已執行：隔離 Chromium 原型

`prototypes/ux01/index.html` 與 `smoke.mjs` 驗證 1000px 和 390px 兩組，皆通過。涵蓋鍵盤模式按鍵、觸控選取、切語言、模式與意圖獨立、Escape 焦點回復、面板點擊隔離、畫面溢位及重新載入。原型用假地圖作事件觀測，沒有 Three.js、遊戲資料或玩家存檔。缺圖及真實遊戲行為列在上表，待正式開發後驗證。

重現方式：在隔離環境以 `python -m http.server 8397 --bind 127.0.0.1 --directory prototypes/ux01` 開啟，再使用 Playwright 已安裝的 Node 環境執行 `node prototypes/ux01/smoke.mjs`（可設定 UX01_URL）。正式候選再跑 npm ci、npm test、npm run build、Playwright 單 worker 零 retries、存檔保護及上述全矩陣。此輪未重跑正式遊戲套件。

下一工作 UX-01-DESIGN-REVIEW，先比對取得的設計原稿並審閱三模式、資料來源及兩版型。G1 與工程授權到位後安排正式實作。
