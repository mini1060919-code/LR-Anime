# E-03｜Three.js 地圖操作與安全區 v0.1

以 `src/core/input.js` 的 canvas 點擊、拖曳與全域鍵盤，以及 `src/main.js` 註冊行為為基線。桌面建造控制置底並保留中央視野；1000px 主面板不超過可視高度 40%，390px 使用可捲動底板且收合控制及取消常駐。使用 viewport 實測及 safe-area inset，縮放與旋轉重算；進入窄屏不更改已存模式。

UI 的 pointer 起點阻隔地圖動作，畫布起始拖曳跨到面板仍延續至 pointerup。鍵盤在輸入欄、含下拉按鍵或對話框時由 UI 控制，Esc 先處理最上層 UI，沒有 UI 接管才走遊戲取消。不要卡住全域鍵盤釋放；焦點失效或切頁重置手勢。驗收以地圖 tile 點擊、拖曳、縮放及全域快捷鍵的事件數比對，面板內操作應為零次地圖事件。
