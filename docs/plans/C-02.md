# C-02｜居民與防禦報告 v0.1

企劃交付，設計審查及正式工程待辦。來源同 [C-01](C-01.md)。

| 摘要或明細 | 欄位與證據 |
|---|---|
| 居民 | 以 survivor.id 關聯角色紀錄，依 survivor.buildingId 看分派；工作可用性沿用 `src/needs/simulation.js:onDuty` 的建築、電力、啟用、職位與名單判定。已分派但未上工要分開顯示。 |
| 需求 | health、fatigue、morale 取黎明採樣，保留原 0～100 值，沿用 `src/needs/rules.js` 的文字分級。缺紀錄的居民列為未知，統計附有效樣本數。 |
| 防禦 | `BUILDING_DEFS.isTower` 識別塔，依 `src/zombies/combat.js` 的啟用、供電與有工人條件（另需存活）顯示可用與受阻原因。以 id、defId、hp/maxHp、職位及名單呈現；此摘要只涵蓋塔。 |
| 戰鬥與損失 | kills 為累計，同 run 相鄰快照可計擊殺差。deathsToday 在聲望更新前取得，顯示全因死亡。現行 events 只保留近期 day/phase/type/msg，不能用文字或前後人口差推算完整戰損或傷亡原因。沒有可信分類即標示未知。 |

摘要按受阻原因與健康級別分組，明細依穩定 ID 排序，無法驗證歷史時不顯示歷史結論。待工程審查結構化戰損證據與事件 ID，沿用既有事件產生點。驗收以有工、無工、停電、停用、缺角色紀錄、人口同時招募及死亡的合成資料核對所有分類；尚未執行。
