# E-02｜建築資訊 v0.1

沿用 `src/ui/buildmenu.js` 的 ICONS、成本及既有 tooltip，資料來自 `BUILDING_DEFS`、`TECHS` 和 isUnlocked。資訊順序為圖示＋名稱、是否可用及原因、成本、用途、科技／地形與建造細節。完整模式顯示每個資源的文字或可存取名稱、需求與不足；精簡模式保持可聚焦詳情入口。科技鎖定與資源不足分別呈現，條件更新來自現有遊戲檢查。

靜態產率標示「基礎」，不得當作實際產量。地形與碰撞由既有 placement 於選定格驗證，無格位先顯示條件。缺圖保留通用圖示及名稱；同形圖示以不同文字區分。驗收覆蓋多資源、免費、科技鎖、資源不足、地形不合、缺圖及鍵盤／觸控，正體中文與英文同一資料來源。
