## 例外與狀態銜接

- B-03 依功能可用性呈現，已有有效派工可認列。無人可派、缺空位或缺防禦介面時保留非阻塞入口。完成提示後交給 B-04，無須建造或改派居民。
- B-04 首夜提示過期即讓位給下一個符合條件的步驟。無夜襲或缺可信歷史皆提供通用入口。確認黎明但沒有日報時保留該黎明的待查看入口，待 C 提供相符快照。
- 稍後繼續保留步驟與暫停偏好。恢復時依可靠狀態重新判斷。取消略過保留原步驟，確認略過只將該步標為 skipped。重播可讀已完成或略過步驟，語言更新保留步驟、模式與焦點。重播與切換語言無進度或結算副作用。
- C 依遊戲進度 ID ＋黎明日序產出唯一快照及日報 ID。跨日或重載時 B 仍以原黎明定位，並沿用 C 的 ID。缺資料時顯示待查看，不用其他進度或日期的快照補位。

## 驗收矩陣

以下皆待執行。測試使用合成存檔與可控時鐘。在同一遊戲時間比較操作前後的引導狀態、時鐘、資源、人口、角色 ID、派工、防禦、戰鬥結果及備份位元組。針對跨日操作先讓下一日正常結算，再取基準檢查重播的增量。日報測試同時觀測結算呼叫、持久化寫入、日報筆數、ID 與快照內容，避免只驗證畫面。

| 案例 | 操作 | 必須觀察到的結果 |
|---|---|---|
| B06-01 | 新檔進入居民→工作→防禦，再用已有派工／無空位分支重驗 | 正確順序與完成原因。已有派工只認列一次，缺空位可繼續遊戲。B-01／B-02 銜接驗收待原稿。 |
| B06-02 | 暫停，重載後手動恢復。分別使目標仍有效、已達成或首夜提示已過期 | 暫停期間無自動提示。恢復後返回原步、認列可靠狀態或銜接下一個適用提示。 |
| B06-03 | 取消略過，兩次確認略過同一步，再重播 | 取消保留原狀態及焦點。確認只記一次 skipped，無獎勵、無派工，重播不修改紀錄。 |
| B06-04 | 有夜襲、無夜襲、歷史不明三種情境重載 | 只有可信事件能顯示夜襲文案。無歷史時通用入口可用，無虛構事件或補發結算。 |
| B06-05 | 原黎明結算後重播、重開日報、切換繁中／英文、重載，跨日後再重播 | 原黎明 ID 與快照資料相同。原黎明結算及日報寫入各一次，這些操作新增呼叫及寫入各零次，遊戲資料依同時間基準相同。 |
| B06-06 | 確認黎明但移除對應快照，再讓 C 提供同日報告，另放入其他進度、前後日快照 | 尚未就緒時顯示待查看且 B 寫入零次。只開啟原進度、原黎明的 C 快照。 |
| B06-07 | 每個 v4/v5/v6 合成檔缺引導歷史時載入，另測未知版讀取與儲存 | 舊檔可正常操作，保留角色 ID 及備份。未知版拒寫，原檔與備份位元組相同。 |
| B06-08 | 1000px、390px 以鍵盤及觸控操作兩語介面 | 可操作暫停、恢復、取消、略過、重播與日報，焦點回復且基地控制可用。 |
