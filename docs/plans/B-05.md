## 狀態與日報契約

- 沿用 B-03 的穩定步驟 ID 與 pending／active／completed／skipped。暫停以引導顯示偏好表達，保留目前步驟；確認略過才將當前步驟標為 skipped，無完成獎勵。重複確認只接受一次。後續啟用條件維持原規格。
- 恢復時依當前可靠事件及狀態重新判斷。仍有效則顯示該步；已達成則依 B-03 的認列原因紀錄；已錯過提示時依 B-04 例外轉到下一個符合條件的步驟或待查看入口。未知歷史顯示通用引導，無法據此認列夜襲或完成步驟。
- 重播僅操作暫時的畫面狀態。關閉、重播及切換語言都不變更教學進度、資源、人口、角色、戰鬥結果或遊戲時鐘。語言切換依原文案鍵更新畫面，保留選定的步驟、模式與日報連結。
- C 擁有每個遊戲進度及黎明日序對應的一次性快照和日報 ID。B 以該組合唯讀取得日報 ID，保存或傳遞連結時沿用 C 的 ID。換語言、暫停、恢復、重載及重播仍指向原黎明，即使已進入下一天。缺快照顯示待查看，日後僅連結相符快照。這些操作不提交結算事件、不建立備用日報、不寫入備份。日報 idempotency 由 C-01／C-06 驗證。
- 工程定義持久化前先核對 v4/v5/v6 欄位與遷移。缺引導欄位的舊檔可正常遊玩，歷程預設未知；未知版本沿用拒絕覆寫，測試使用合成存檔，保留備份與既有角色 ID。
