# E-05｜建築與居民面板連動 v0.1

候選既有 `src/ui/characterpanel.js`、laborpanel、inspector 及 `src/progression/assignments.js:assignResident` 為單一操作路徑。建築選取帶 buildingId，角色詳情帶 run.id／survivor.id 的既有 uid。派工是顯式操作，選取、跳轉、重播或換語言均唯讀。

流程為建築→職位摘要→居民詳情→確認派工→重讀兩面板。正式接線提案向既有派工函式傳 residentId/buildingId，先核對同 run、有效員額及建築狀態，照現有回傳顯示原因；無效時保留已提交狀態。取消與返回焦點回原列表。建物拆除、居民死亡或切換存檔時清除失效連結，不依同名或重用數字 ID 跨存檔定位。角色面板與 D-05／D-ART 共用提案 2:3 頭身容器、48px／64px 頭像，路徑獨立於角色 UID。驗收滿員、停用、居民有既有職位、刪除、切語言及兩面板結果一致。
