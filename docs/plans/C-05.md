# C-05｜基地日報 UI／UX v0.1

設計規格待審查與試玩。由既有 HUD 提供「基地日報 / Base reports」，B-04 可帶入特定 reportId。預設開最新已提交日報。若 B 提供特定 ID 或黎明鍵，保留指定日期，缺報告顯示待查看。

| 區塊 | 資訊與操作 |
|---|---|
| 頁首 | 日期、歷史選擇、關閉。載入中、歷史空白、暫不可用及已載入狀態可辨識。 |
| 摘要 | 優先警示、人口及各項庫存和容量。數字保留資源單位。 |
| 趨勢 | 黎明庫存與前一日淨差，另提供可讀數值表。日序缺口保留空白。 |
| 居民 | 分派、工作狀態、健康、疲勞、士氣。按既有穩定居民 ID 前往角色面板。 |
| 防禦 | 塔可用／受阻原因與已知損失。按既有建築 ID 前往檢視器。 |
| 澪的建議 | 非強制的雙語建議，展開依據，依警示提供既有居民、派工或建築畫面的入口。 |

桌面規劃側面板，390px 使用單欄可捲動面板，保留可見的關閉鍵。Three.js 場景及原控制維持原行為。面板取得焦點時阻隔該次操作傳入場景，退出後焦點回原按鈕。可 Tab 操作、Esc 退出，狀態與趨勢以文字及符號呈現。語言切換保留日報 ID、分頁與項目焦點。歷史目標已移除時保留快照，捷徑停用並說明；切到現行檢視器時標示「目前狀態」。待以 1000px／390px、兩語、鍵盤／觸控檢查版面、焦點及地圖回復。
