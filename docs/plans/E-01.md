# E-01｜建築選單三模式 v0.1

以治理 E、UX-01 與鎖定候選 `cfa103c659aeb68aa97b448746ac944bbb16fd0d` 為基準。已查 Git 路徑歷史與可見附件，找到既有設計完成紀錄、M2 介面文件與程式，原 Figma／設計原檔待取得。以下補足可審查的操作契約。

| 模式 | 顯示 | 轉換 |
|---|---|---|
| 完整／Full | 分類、圖示、名稱、成本與既有取消／拆除 | 模式切換列可精簡、收合 |
| 精簡／Compact | 分類與等高按鍵，名稱可讀，詳細成本移入可聚焦的詳情 | 可展開或收合 |
| 收合／Collapsed | 模式控制和目前操作的取消入口，地圖保留空間 | 可直接回完整或精簡 |

模式獨立於 placement／demolish 與選中建築；切換不取消目前意圖，離開建造仍走原 cancel。焦點在切換控制上保持；若外部導致焦點所在卡片收合，移回模式列。偏好用專用 UI 鍵，與遊戲 Checkpoint 分離。首次或無效值預設精簡；語言與視窗變化不重置選擇。讀寫失敗當次仍可操作，由原遊戲正常部件接管實作。
