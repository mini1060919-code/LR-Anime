# M5-B 居民自主休息與工作優先級

基準：M5-A `002529e38d072f39f9af137b14de5206fee5d672`，分支 `feature/m5b-survivor-autonomy`。本分支供 M5-A 分支驗收，不合併任何前置 PR、不部署。

## 行為規格

排程沿用主迴圈每 2 遊戲秒執行一次的 `assignJobs`；沒有新增瀏覽器計時器或離線補算。冷卻以 M5-A 的 `survival.elapsedSeconds` 計時，暫停、讀檔與遊戲日切換不會重設。

- 所有居民（含手動指定者）疲勞達 85 時進入休息、釋放實際工作槽。
- 疲勞降至 35 以下且至少休息 10 遊戲秒後，才可返工。重複排程不會延長休息截止時間。85/35 遲滯避免頻繁切換。
- 健康低於 50 者的新派工順位較低；沒有強制住院、疾病或額外死亡規則。必要工作仍可由健康較低者承擔。
- 手動命令保存「指定建築」或「手動待命」意向。休息不刪除指定建築。恢復後先返原指定建築，必要時釋放一位自主工作者；絕不搶另一位手動居民的工作槽。滿員皆為手動者時繼續等待。
- 手動待命不會被自動派工；玩家可在角色面板選擇恢復自主。建築的 Auto 命令會解除該建築目前及等待中的手動意向；不影響其他建築。
- 關閉建築釋放實際工作槽，保留手動目標待重新開啟；拆除則解除其目標，避免懸空參照。關閉中的建築可以預先設定 Auto，但不會派工。
- 現有有效工作不因小幅分數變化重新洗牌。只處理休息、無效工作及空缺。

## 派工排序（確定性）

可自動派工的建築須啟用、HP > 0、有工作容量且 Auto 開啟。排序依序為：

1. 玩家建築優先級（高至低）。
2. 基地需求：食物 < 30／飲水 < 20 時急迫度 3；能源 < 5／燃料 < 5 時急迫度 2。
3. 原版類別：食物、飲水、採集、研究、其他。
4. 建築 ID。

候選居民依序比較：健康至少 50 優先、職業對應技能 +20 與技能等級 ×5 的分數、較低疲勞、居民 ID。技能映射沿用 M4；分數只用於派工，不直接生產資源或授予經驗。自主工作者讓位時依相同比較取較低順位者。

## 邊界與 UI

排程重建居民與建築的雙向工作參照，檢查存活、容量及去重。手動命令經核心驗證；UI 不直接寫 workers。舊版 +/- 工作控制仍可使用；UI 的可派工人數另行排除休息者，原版 `idleCount` 不改動。

角色面板保留肖像、技能、經驗及疲勞／健康／士氣，新增自主／手動／休息狀態、保留工作目標及切換控制，支援繁中／英文。

休息是退出日常工作，不是免除戰鬥：原版 HQ 待命居民防衛保持，戰鬥仍可造成疲勞。Three.js 地圖、攝影機、夜襲、傷亡、原有建築與經濟公式均未重寫。居民休息會減少實際在崗時間，因此總產量會下降；沒有新增無上限產量加成。防衛建築也適用相同休息規則，夜間可能暫時缺員；本階段沒有緊急作戰豁免，需人工觀察防線配置。

## 限制與回復

這是有限排程器，沒有路徑、社交、疾病、複雜情緒或自動治療 AI。低健康不會替玩家規劃治療。優先級變更影響後續空缺，不會立刻撤換正常工作者。依居民數排序，尚未對極大人口專門效能最佳化。

回復請切回 M5-A 基準；先匯出 M5-B 完整 JSON，並保留升級前永久備份。M5-A 不認得 autonomy-v1，會拒絕新版存檔；不能直接降版讀取而保留自主意向。詳見存檔報告。
