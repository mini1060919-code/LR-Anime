# LR-Anime｜PLAYTEST-03｜分批修正、測試、驗收與風險計畫

**目的**：確保遊戲能繼續生存、玩家能看懂及操作、角色與教學體驗符合原規劃。這是原始工程主線的品質修正插入工作，**不是取代** [原始 M0～M11](../milestones/README.md) 或 A～E 計畫。

## 工程順序與工作批次

**Gate 0：唯讀現況盤點（新 GPT / Codex 首個工作）**
1. 重新查 GitHub PR #10、#12、#13、#19、#24、#25 與本文件所在 Draft PR；確認 Base、Head SHA、Draft、合併情況及 G1。
2. 查 Owner 試玩 ZIP 真實 SHA、所含 Git commit、PT02-06 候選修正，以及 UX-BUILDING-VISIBILITY-02 是否真已套用。
3. 查 Codex 本地工作區原始證據和前次測試；不存在即明確標記，不可宣稱可讀。
4. 調查資源收支、建造、居民自主/手動派工、教學觸發及 UI 實作；提供根因/不確定點、修改檔案與回復計畫。

**批次 A：P0 教學後生存可持續**
- 先算「完成教學後食物、水的每日淨收益、剩餘資源、可建造生產建築、人力／電力條件」的真實值；用 deterministic seed 重現。
- 設計並比較「降低初始壓力／改教學資源配置／提升可工作產能／改善派工引導」等最小方案；不得一律暴增初始資源。
- 自動及 Owner 驗收：從全新遊戲完成帳篷→食物來源→水井到防禦等新手關卡，繼續至少數個遊戲日或足以觀測收支的時間；能透過合理操作穩定食水並獲得清楚提示。具體天數與數值門檻應由本批方案提出供 Owner 核定，不可假裝已定案。
- 保留原建造成本和完整收支/時間序列紀錄；檢查手動/自主派工影響。

**批次 B：P1 教學面板／中央選單（高影響 UX）**
- 教學面板移至安全區或可拖移／收合，避免覆蓋指定放置區，保留可見目標與進度。
- 中央選單支援展開、收合、關閉／取消、Escape 與 390px 手機點擊；展開與收合狀態可預測。
- 驗收：桌面 1280×900、手機 390×844、實際建造點選操作；原「建造、選取、取消、拆除」回歸 PASS。

**批次 C：P1 建築辨識度**
- 先檢查 Owner ZIP 版本。若缺 patch，先提供含候選的正確隔離試玩；若已含 patch 而 Owner 仍看不清，再設計本體幾何/輪廓、主色、可讀性、雨天／夜間對比的最小修正。
- 固定 seed、相機、時段與顯示比例 Before/After；同時檢查鄰棟命中與選中提示；Owner 必須實看。

**批次 D：P1 角色派工與參謀澪**
- 查特殊角色與一般居民的不同職責、手動派工、工作效率、預設自主行為、角色 UI、M6-A 教學員的觸發規格。
- 對比「無派工／手動派工／自主工作」的真實產出與可視數值；若遊戲設計尚未實裝，標記缺功能，不得把 UI 假資料當有效果。
- 教學員出現應符既有角色契約；新角色素材 0 APPROVED 不得無授權接線。

**批次 E：P2 背景音樂**
- 在上述核心體驗穩定後才做原創或可驗證使用權的 BGM 設計。包含互動後啟播、音量及靜音、BGM/SFX 分離、淡入淡出、偏好儲存；不得擅用受限制音樂。

## 驗收狀態分類

`REPORTED`／`INVESTIGATING`／`ROOT_CAUSE_CONFIRMED`／`CANDIDATE_READY`／`AUTO_TESTED`／`OWNER_PASS`／`NEEDS_FIX`／`DEFERRED_BY_OWNER`。

各項需記錄：候選/基準 Git SHA、完整補丁 SHA、實際試玩 ZIP SHA、重現場景、步驟、截圖、控制台、Vitest/Build/Playwright、真實存檔隔離與回復方式。自動測試 PASS 不能代替 Owner 感受驗收。

- 本輪屬 **docs-only 策劃與交接**；任何新的遊戲候選實作、GitHub 程式 PR 或廣泛素材使用需另取得 Owner 具名/具範圍授權。
- G1 **NO-GO**；不能改 `main`、`develop`，不能合併、部署、force push、刪分支或修改真實玩家 v4/v5/v6 存檔。
- 可在明確獨立授權後使用隔離 worktree 做最小候選；先檢查 patch 可逆、同基準測試，再交 Owner。
- Owner 延後「人工存讀檔驗收」，**不等於可以省略 v4/v5/v6/未知格式自動保護測試**。
- 正式工程原順序仍為 G1 → UX-01 → M5-C → M6-A → M6-B → M6-C → M6-D → M7 → M8 → M9 → M10 → M11；PLAYTEST-03 只可隔離開展並等待相應整合批准。
