Base：`feature/m2-zh-tw-anime-ui`。依賴 M1 #1、M2 #2；請勿合併到 main 或部署。

原有居民僅有數字 ID 與工作／生存狀態，本次加入穩定 runId/UID、雙語姓名、職業、個性及外觀 ID，並保存 ID 高水位，避免死亡後讀檔重用角色身分。人物能力資料尚不產生任何效果，保留原有 AI 與經濟。

v6 同時保存原 core 與角色資料；v4/v5 安全遷移及 JSON 匯入保留永久原文備份。損壞、未知版本、未知必要欄位與遷移失敗均保護原檔。提供明確提示的下載專用 v5 相容副本，降版會失去 M3 資料。
